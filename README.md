# ZeroTrust
A fun, interactive way to learn about the dangers that lie within the internet
# Description
- A web app made with HTML, CSS, and JS; it has two modes for users to interact with. 
 - One is the lesson mode, which has 6 modules that cover a different topic of online safety. At the end of each module, there is a quick check to make sure users have a grasp of the content. 
 - The Second Mode is the Click the Red Flag game mode in which users have to identify the malicious part of the image, and, in doing so, they get a certain number of points out of 800. Each image presented can give up to 100 points.

## Getting Started
### Dependencies
* Any modern web browser (e.g., Google Chrome, Mozilla Firefox, Microsoft Edge, Safari).
* Visual Studio Code with the **Live Server** extension installed (optional for local development preview).

### Installing
1. Download or clone the repository to your computer:
   
```bash
   git clone https://github.com/EPProjects/ZeroTrust2.0.git
```

### Executing the Program
* Option 1(VS Code Live Server): Right-click index.html in VS Code and select Open with Live Server
* Option 2(Direct Browser): Open index.html directly in any web browser
